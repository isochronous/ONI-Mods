# Tags

## harmony-patching
**Id:** blk-5f8516e53275

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## vanilla-fallback
**Id:** blk-e21fb1be2c8b

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-714d110d7cb5

A record earns this term when it is about what a mod writes to the game log and at which level.

## saved-state
**Id:** blk-df45110666b5

A record earns this term when it is about what a mod stores in a save file and how that data is restored when the save loads.

## copy-settings
**Id:** blk-25d99e32de9e

A record earns this term when it is about how a building's settings travel to other buildings through the game's copy-settings tool.

## in-game-testing
**Id:** blk-c18cb7efa41f

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-849f474cfbdb

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-1e8c0248fc1e

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## game-component
**Id:** blk-893709d333c8

A record earns this term when it is about a KMonoBehaviour component that a mod adds to game objects and the work it does there.

## side-screen
**Id:** blk-e995932c681f

A record earns this term when it is about a building's details-panel side screen that a mod adds or changes.

## building-config
**Id:** blk-8873714c474f

A record earns this term when it is about the definition of a building a mod adds through an IBuildingConfig class.

## building-unlock
**Id:** blk-dfd1ee7ed7c9

A record earns this term when it is about how a mod's building is placed in the build menu and unlocked by research.

## kanim-art
**Id:** blk-688e20eaecb6

A record earns this term when it is about the kanim animation art a mod ships or swaps onto a building and how that art is made.

## automation-ribbon
**Id:** blk-c8563eef603d

A record earns this term when it is about the Automation Ribbon and the multi-bit signals it carries.

## critter-sensor
**Id:** blk-060dd3e4f3a8

A record earns this term when it is about the game's critter sensor and how it counts the critters and eggs in a room.

## signal-threshold
**Id:** blk-edf02ef5d871

A record earns this term when it is about the threshold values an automation sensor compares against to decide its output signal.

# Tags

## harmony-patching
**Id:** blk-57067fa712d1

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## vanilla-fallback
**Id:** blk-62f6c2064b32

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-0a8b4ec9048f

A record earns this term when it is about what a mod writes to the game log and at which level.

## mod-options
**Id:** blk-1f76cf54464e

A record earns this term when it is about the player-facing settings a mod exposes on its options screen and how the mod reads them.

## in-game-testing
**Id:** blk-aec99064b2f7

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-c8fccbd89209

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-83ba5485e0cf

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## reflection
**Id:** blk-eaa6cf0c9c87

A record earns this term when it is about reaching non-public members of the game or of another mod through reflection.

## game-component
**Id:** blk-a642d739f405

A record earns this term when it is about a KMonoBehaviour component that a mod adds to game objects and the work it does there.

## automation-ribbon
**Id:** blk-0df731cb0525

A record earns this term when it is about the Automation Ribbon and the multi-bit signals it carries.

## bridge-end
**Id:** blk-ee12547a1458

A record earns this term when it is about a wire or automation bridge end placed on a port cell and the stand-in node that connects it.

## utility-network
**Id:** blk-89144003eaaa

A record earns this term when it is about the game's automation and power networks and how cells are linked into them.

## wire-tools
**Id:** blk-9df1c2e03839

A record earns this term when it is about how the game's wire drag and building tools act on bridge ends.

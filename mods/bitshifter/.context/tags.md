# Tags

## harmony-patching
**Id:** blk-f8a8e15cc990

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## transpiler
**Id:** blk-cee2d0ad9ce0

A record earns this term when it is about a Harmony transpiler that rewrites the instructions of a game method.

## vanilla-fallback
**Id:** blk-6399b918eaa0

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-b3c377c3fa93

A record earns this term when it is about what a mod writes to the game log and at which level.

## mod-compatibility
**Id:** blk-e452b4fa1136

A record earns this term when it is about a mod working correctly alongside other authors' mods installed in the same game.

## saved-state
**Id:** blk-dbab331607e6

A record earns this term when it is about what a mod stores in a save file and how that data is restored when the save loads.

## in-game-testing
**Id:** blk-80d36c918628

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-1129c764f7b8

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## side-screen
**Id:** blk-2ef7dec9b6c1

A record earns this term when it is about a building's details-panel side screen that a mod adds or changes.

## kanim-art
**Id:** blk-00b26a4d4261

A record earns this term when it is about the kanim animation art a mod ships or swaps onto a building and how that art is made.

## automation-ribbon
**Id:** blk-308252926106

A record earns this term when it is about the Automation Ribbon and the multi-bit signals it carries.

## bit-depth
**Id:** blk-4453f9f2ef08

A record earns this term when it is about how many ribbon bits the Ribbon Reader and Writer can select and which bit is selected.

## not-gate
**Id:** blk-ed42d3a953c2

A record earns this term when it is about how the NOT gate inverts the bits of a ribbon signal.

## code-style
**Id:** blk-8c0bf34d14ba

A record earns this term when it is about the house style in which a mod's C# source code is written.

# Tags

## harmony-patching
**Id:** blk-0b95cd397d16

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## logging
**Id:** blk-c1c665e05e96

A record earns this term when it is about what a mod writes to the game log and at which level.

## mod-options
**Id:** blk-ba8545bce097

A record earns this term when it is about the player-facing settings a mod exposes on its options screen and how the mod reads them.

## saved-state
**Id:** blk-9f9a2579dfc8

A record earns this term when it is about what a mod stores in a save file and how that data is restored when the save loads.

## in-game-testing
**Id:** blk-d991ee597d79

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-0ede851d41db

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-0ead12b946d3

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## game-component
**Id:** blk-756918e88828

A record earns this term when it is about a KMonoBehaviour component that a mod adds to game objects and the work it does there.

## developer-tooling
**Id:** blk-3b73dd4898b2

A record earns this term when it is about debug and developer features a mod includes for its author rather than for players.

## liquid-vent
**Id:** blk-eb21c7cacead

A record earns this term when it is about the liquid vent and the packets of liquid it stores and emits.

## liquid-freezing
**Id:** blk-7eced60aa014

A record earns this term when it is about how super-cooled liquid freezes into a tile and the game's mass rule for that.

## tile-repair
**Id:** blk-1334c2fd62bb

A record earns this term when it is about digging out a tile that should not have formed and returning its mass as debris.

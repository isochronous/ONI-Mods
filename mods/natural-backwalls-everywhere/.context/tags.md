# Tags

## harmony-patching
**Id:** blk-73a10fc6bc86

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## transpiler
**Id:** blk-026217966079

A record earns this term when it is about a Harmony transpiler that rewrites the instructions of a game method.

## vanilla-fallback
**Id:** blk-6775b7003021

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-d8e570cc8737

A record earns this term when it is about what a mod writes to the game log and at which level.

## exception-handling
**Id:** blk-d24187f95b99

A record earns this term when it is about where a mod catches exceptions and what it does once it has caught one.

## mod-compatibility
**Id:** blk-297e46c0c0fd

A record earns this term when it is about a mod working correctly alongside other authors' mods installed in the same game.

## mod-options
**Id:** blk-8835da294e88

A record earns this term when it is about the player-facing settings a mod exposes on its options screen and how the mod reads them.

## in-game-testing
**Id:** blk-9effc1ad47e5

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-0b0c30235fc9

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-baeebe3fdd93

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## developer-tooling
**Id:** blk-05b973051415

A record earns this term when it is about debug and developer features a mod includes for its author rather than for players.

## worldgen
**Id:** blk-f7e4c6a542bc

A record earns this term when it is about world generation and the data a mod changes while a new world is generated.

## biome-group
**Id:** blk-0a7807b241d3

A record earns this term when it is about the families of biomes that share one backwall material and coverage setting.

## noise-pattern
**Id:** blk-8c77064fcc8a

A record earns this term when it is about the worldgen noise trees that shape where backwall patches appear.

## settle-sim
**Id:** blk-65a9b112c4f6

A record earns this term when it is about the simulation worldgen runs to settle a new world before play begins.

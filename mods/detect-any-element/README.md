# Detect Any Element

An [Oxygen Not Included](https://www.klei.com/games/oxygen-not-included) mod: the element sensors get an **Any** choice, right under **None** in their side screen.

## What it does

- **Liquid Pipe Element Sensor, Gas Pipe Element Sensor, Conveyor Rail Element Sensor**: on Any, the sensor is green while any packet at all is passing through it, whatever the element or item.
- **Gas Element Sensor, Liquid Element Sensor** (the in-world ones): on Any, the sensor is green while its cell holds any gas (for the gas sensor) or any liquid (for the liquid sensor). Vacuum counts as nothing.

While a sensor on Any is on, the icon that flashes on its screen (a drop, a gas gust or a lump of ore in the base game) is an asterisk; when it is off, the screen looks as it always does.

Picking an element in the list switches Any off, since a sensor has one choice at a time; picking Any switches the element off. The choice is saved with the building and copied with its settings like an element would be. Everything else, including the game's eight-sample steadiness window on the in-world sensors, is the game's own logic with the element test taken out.

Without the mod, a sensor that was left on Any keeps the choice but matches nothing, as if nothing were chosen; pick an element and it is back to normal.

## Installing

As a local mod:

1. Download `DetectAnyElement-<version>.zip` from the [latest release](https://github.com/isochronous/detect-any-element/releases/latest).
2. Extract it into a new folder named `DetectAnyElement` inside the game's local mods folder, so that `mod.yaml` ends up directly inside it (create `local` if it does not exist):
   - Windows: `Documents\Klei\OxygenNotIncluded\mods\local\DetectAnyElement`
   - Linux: `~/.config/unity3d/Klei/Oxygen Not Included/mods/local/DetectAnyElement`
3. Enable it in the game's Mods menu and restart.

## Building

```
git clone --recurse-submodules https://github.com/isochronous/detect-any-element.git
dotnet build detect-any-element/src/DetectAnyElement -c Release
```

The build deploys the mod into the game's local mods folder. See `common/README.md` for the shared build and release tooling.

The asterisk art is generated by `python tools/make_art.py` (Pillow) into `src/DetectAnyElement/anim/assets/detect_any_asterisk/`. Its glyph is the asterisk of Liberation Sans Bold, the game's own UI face, which is under the SIL Open Font License; the font and its licence are in `tools/`.

## Translations

The mod is available in Chinese (Simplified), Korean and Russian. Other languages can be added from the template `src/DetectAnyElement/translations/DetectAnyElement.pot`: save the translation as `translations/<locale>.po` (the game's locale code, for example `ko.po` or `ru.po`) next to the mod's DLL and it loads with that language.

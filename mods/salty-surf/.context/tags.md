# Tags

## harmony-patching
**Id:** blk-b80fc9de0826

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## vanilla-fallback
**Id:** blk-78fc016a0731

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-17c86b5c201b

A record earns this term when it is about what a mod writes to the game log and at which level.

## in-game-testing
**Id:** blk-b5781cd1460f

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-1acac7578088

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-abddd0119bb8

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## reflection
**Id:** blk-6321b9370f6d

A record earns this term when it is about reaching non-public members of the game or of another mod through reflection.

## game-tag
**Id:** blk-1baaf90f3b8b

A record earns this term when it is about a game Tag that a mod creates, adds to things or reads to recognise them.

## mechanical-surfboard
**Id:** blk-c41fb2432929

A record earns this term when it is about the Mechanical Surfboard and the liquid it takes in, holds and spills.

## info-panel-text
**Id:** blk-251f23c41134

A record earns this term when it is about the lines a building shows in its info panel.

## code-style
**Id:** blk-e7c517726889

A record earns this term when it is about the house style in which a mod's C# source code is written.

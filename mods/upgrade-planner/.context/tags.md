# Tags

## harmony-patching
**Id:** blk-3c4851341746

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## vanilla-fallback
**Id:** blk-6bce482f6734

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-4e34a9933fda

A record earns this term when it is about what a mod writes to the game log and at which level.

## exception-handling
**Id:** blk-3f8dff04df94

A record earns this term when it is about where a mod catches exceptions and what it does once it has caught one.

## mod-compatibility
**Id:** blk-c482e7b9f27a

A record earns this term when it is about a mod working correctly alongside other authors' mods installed in the same game.

## in-game-testing
**Id:** blk-ebe567a99bb9

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-e8ef6c08bacf

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-43db226091b5

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## reflection
**Id:** blk-aa57c6f3b527

A record earns this term when it is about reaching non-public members of the game or of another mod through reflection.

## toolbar-tool
**Id:** blk-bc4966a3111d

A record earns this term when it is about a drag tool a mod adds to the toolbar and how the player uses it.

## hotkey
**Id:** blk-24f3a3265d3f

A record earns this term when it is about the rebindable key a mod registers to open its tool.

## performance
**Id:** blk-84e00cb42e82

A record earns this term when it is about keeping a mod's per-tick or per-frame work cheap enough that it does not slow the game.

## building-materials
**Id:** blk-abf680c115f1

A record earns this term when it is about which materials a building recipe accepts and how a building's material is chosen.

## building-replacement
**Id:** blk-22d5b6cecef8

A record earns this term when it is about building one building over another and the game's rules for which pairs are allowed.

## plan-presets
**Id:** blk-45c2e435b1b2

A record earns this term when it is about named plans a player saves and loads back in any colony.

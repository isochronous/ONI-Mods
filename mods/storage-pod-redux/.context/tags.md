# Tags

## harmony-patching
**Id:** blk-13b5338c05ca

A record earns this term when it is about writing or applying the Harmony patches through which a mod changes game methods.

## vanilla-fallback
**Id:** blk-471346fd5a29

A record earns this term when it is about how a mod keeps the game's own behaviour when something it depends on is missing or has changed.

## logging
**Id:** blk-395c0fa66909

A record earns this term when it is about what a mod writes to the game log and at which level.

## mod-compatibility
**Id:** blk-53a498e525c2

A record earns this term when it is about a mod working correctly alongside other authors' mods installed in the same game.

## mod-options
**Id:** blk-55b60312ac04

A record earns this term when it is about the player-facing settings a mod exposes on its options screen and how the mod reads them.

## saved-state
**Id:** blk-928a515ba85f

A record earns this term when it is about what a mod stores in a save file and how that data is restored when the save loads.

## in-game-testing
**Id:** blk-2759a6a35b93

A record earns this term when it is about testing a mod inside the running game with TestRunner and its [OniTest] coroutines.

## mod-entry-point
**Id:** blk-1319bf3d778c

A record earns this term when it is about a mod's UserMod2 class and what it does when the game loads the mod.

## mod-strings
**Id:** blk-9d08577547e5

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## building-config
**Id:** blk-fda464cfd967

A record earns this term when it is about the definition of a building a mod adds through an IBuildingConfig class.

## building-unlock
**Id:** blk-cdb67a62cb31

A record earns this term when it is about how a mod's building is placed in the build menu and unlocked by research.

## kanim-art
**Id:** blk-f3b112f68b53

A record earns this term when it is about the kanim animation art a mod ships or swaps onto a building and how that art is made.

## refrigerator
**Id:** blk-dc276926b8dc

A record earns this term when it is about the game's refrigerators and how they keep stored food cold.

## building-registration
**Id:** blk-0a1f11b070de

A record earns this term when it is about deciding whether a mod's building is registered with the game at all.

## storage-building
**Id:** blk-2db9f30eb94a

A record earns this term when it is about a building that stores items and what it accepts.

## code-style
**Id:** blk-92d1217132e0

A record earns this term when it is about the house style in which a mod's C# source code is written.
